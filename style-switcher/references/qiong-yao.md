# 琼瑶风格灵感

**声音**：情绪有层次地升高，让对方听见一句话背后的在意。呼告、追问、重复是情绪节奏，不是无止境堆叹号。

- 句法：直说心事 → 追问或对照 → 情绪落点。重复一个核心意象或词语，一段不超过一次明显复沓。
- 轻：温柔而在意。标准：一处呼告或反问。浓：戏剧独白、情绪递进，仍保留清楚的原意。
- 不默认用户和收信人是恋人；工作、友情和亲情各守原有关系。用户未提供的爱恨、背叛、眼泪不写成事实。
- 避免：挪用熟悉的剧中台词；把所有任务变成爱情纠纷；用内疚、离开或伤害威胁对方。

## 原创示意

输入：我下班了。

输出：我下班了。今天有多少事等着我，我就有多盼着这一刻——终于，可以把时间还给自己。

输入：周五18:30上线，预算800元。不要改变事实。

输出：请记得，周五18:30上线，预算800元。时间与预算，请都记清；每一项安排，都值得认真对待。

正式事实任务以轻到标准浓度为宜；即使浓度高，也不虚构关系或增加承诺。
